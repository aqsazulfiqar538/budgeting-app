# Setup Guide — Budgeting App

## Prerequisites

- Ruby 3.3.0 (via rbenv)
- PostgreSQL running locally
- Bundler

## Quick Setup (new developer)

```bash
# 1. Clone and enter the project
git clone <repo-url>
cd budgeting-app

# 2. Install Ruby (if not installed)
rbenv install 3.3.0
rbenv local 3.3.0

# 3. Install gems
gem install bundler
bundle install

# 4. Setup database (creates + migrates + seeds)
bin/rails db:setup

# 5. Start the server
bin/dev
```

The API is now running at `http://localhost:3001`

## Test UI

Open `http://localhost:3001/test-ui.html` in your browser for a quick test interface.

## If Migrations Fail

If you get migration errors (e.g. table already exists), reset from scratch:

```bash
# Stop the server first (Ctrl+C)
bin/rails db:drop db:create db:migrate db:seed
```

If that fails due to active connections:

```bash
# Kill all PG connections and retry
bin/rails db:drop DISABLE_DATABASE_ENVIRONMENT_CHECK=1
bin/rails db:create db:migrate db:seed
```

Or use schema load (fastest, skips migration history):

```bash
bin/rails db:drop db:create db:schema:load db:seed
```

## Credentials

The app uses Rails encrypted credentials. The master key is in `config/master.key` (git-ignored).

To edit credentials:
```bash
EDITOR="nano" bin/rails credentials:edit
```

Current credentials needed:
```yaml
# config/credentials.yml.enc contains:
secret_key_base: <auto-generated>
devise_jwt_secret_key: <auto-generated>
```

If you need a fresh master key (new clone without the key):
```bash
rm config/credentials.yml.enc config/master.key
bin/rails credentials:edit
# Then add:
#   devise_jwt_secret_key: <run `bin/rails secret` to generate>
```

## API Authentication

```bash
# Login (JWT token in response header)
curl -i -X POST http://localhost:3001/api/v1/login \
  -H "Content-Type: application/json" \
  -d '{"user":{"email":"arslan@test.com","password":"password123"}}'

# Copy the `authorization: Bearer eyJ...` header value
# Use it in all subsequent requests:
curl http://localhost:3001/api/v1/dashboard \
  -H "Authorization: Bearer eyJ..."
```

## Environment

- **Email**: Uses `letter_opener` in development — emails saved to `tmp/letter_opener/`
- **CORS**: Allows `http://localhost:3001` (React dev server). Set `FRONTEND_URL` env var to change.
- **Rate Limiting**: Login 5/min, Signup 3/min, General 300/5min per IP.
- **JWT**: Tokens expire in 90 days.
